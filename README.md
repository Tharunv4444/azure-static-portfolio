# Vipperla Tharun — Multi-Cloud DevOps Engineer Portfolio

## 📌 Project Overview

This project is a personal portfolio website created to showcase my profile, technical skills, DevOps knowledge, projects, internships, education, and resume.

The portfolio is developed using HTML, CSS, and JavaScript and deployed as a static website using **Microsoft Azure Blob Storage Static Website Hosting**.

The project demonstrates practical experience with cloud storage, static website hosting, Git version control, GitHub, and Azure deployment workflows.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Create a professional personal portfolio website.
- Host a static website using Microsoft Azure Storage.
- Configure Azure Blob Storage for static website hosting.
- Configure the `$web` container.
- Upload HTML, CSS, JavaScript, and resume files to Azure.
- Deploy the website and make it publicly accessible.
- Upload the complete source code to GitHub.
- Document the deployment process.
- Gain practical hands-on experience with Azure cloud services.
